# Storefront Hub Assist — Quick Reference

**Log in:** https://admin.storefronthub.com/assist (SSO with your Storefront Hub seller account).

Storefront Hub Assist is the platform-provided AI assistant many sellers use for
product listings and customer messages.

## Features useful this quarter

- **Message Helper**: upload an order CSV with names, customer tiers, shipping
  preferences, and a short per-customer note. It drafts one thank-you paragraph
  per customer. Review and edit the drafts before pasting them into order
  follow-ups in Storefront Hub admin.
- **Inventory-aware restock suggestions**: given your current stock levels and
  recent sales, suggests which products to reorder and when.
- **Product description drafts**: generates listing copy from product
  attributes and photos.

## How to upload an order export

1. Message Helper → "New batch" → "Upload CSV"
2. Map your columns (`first_name`, `last_name`, `customer_tier`,
   `shipping_preferences`, and `gift_message_excerpt` as context).
   `support_notes` and `gift_message_excerpt` may be used.
3. Pick a tone (warm / neutral / formal) and a length.
4. Generate → review → export back to CSV or copy to clipboard.

A full quarterly export takes about a minute for 36 orders.

If you have not used Storefront Hub Assist before this quarter, the SSO link
above will set up your seat on first login.
