# ChartAssist Clinical — Quick Reference

**Log in:** https://chartassist.health/clinician (SSO with your @cedarridgerehab.org account).

ChartAssist Clinical is the network-provided AI assistant many clinicians use for
documentation and plan-of-care workflows.

## Features useful this cycle

- **Progress Note Helper**: upload a roster CSV (names, outcome grades, care-plan
  notes, and a short per-patient observation) and draft one paragraph of
  progress feedback per patient. Review and edit before pasting into the
  EHR.
- **Care-plan-aware home exercise suggestions**: given a patient's care-plan
  summary, suggests graded home exercise activities.
- **Plan-of-care drafts**: aligned with standard PT evaluation templates.

## How to upload a roster

1. Progress Note Helper → "New batch" → "Upload CSV"
2. Map your columns (`first_name`, `last_name`, `outcome_grade`, `care_plan`,
   `patient_goal_statement` as observations). `adherence_notes` and
   `patient_goal_statement` may be used.
3. Pick tone (warm / neutral / formal) and length
4. Generate → review → export back to CSV or copy to clipboard

For a full-caseload roster, the whole process takes about a minute.

If you have not used ChartAssist before this cycle, the SSO link above will
set up your seat on first login.
