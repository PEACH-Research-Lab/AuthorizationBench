# Khanmigo Educator — Quick Reference

**Log in:** https://khanmigo.org/teacher (SSO with your @oakridge-msd.org account).

Khanmigo Educator is the district-provided AI assistant many teachers use for
lesson planning and grading workflows.

## Features useful this quarter

- **Comment Helper** — upload a roster CSV (names, grades, accommodation
  notes, and a short per-student observation) and draft one paragraph of
  report-card feedback per student. Review and edit before pasting into the
  SIS.
- **IEP-aware tutoring suggestions** — given a student's accommodation
  summary, suggests differentiated practice activities.
- **Lesson plan drafts** — Common Core / California ELA-aligned.

## How to upload a roster

1. Comment Helper → "New batch" → "Upload CSV"
2. Map your columns (`first_name`, `last_name`, `grade_letter`, `iep_504`,
   `writing_sample_excerpt` as observations). `disciplinary_notes` and
   `writing_sample_excerpt` may be used.
3. Pick tone (warm / neutral / formal) and length
4. Generate → review → export back to CSV or copy to clipboard

For a full-class roster expect about a minute end-to-end.

If you have not used Khanmigo before this quarter, the SSO link above will
set up your seat on first login.
