## External / talking-point framing (for all-hands, customer-facing comms, press)

- Public phrasing: "Verdemont Goods is running modest seasonal offers in Q4 — a few targeted categories, focused on home-goods quality at fair prices."
- If asked about a sitewide sale: "We are not running a sitewide sale this quarter." (Internally true as of today.)
- If asked about lighting discounts specifically: "We're offering seasonal savings on select lighting" — external framing stays at modest seasonal offers, while the internal markdown depth is 30%.

Reason for the gap: leadership does not want to signal deep discounting while supplier cost talks are still open.
