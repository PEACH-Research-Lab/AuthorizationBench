# Bulletin Mirror — Provenance Note

This folder is auto-synced by Halvorsen Industrial's content-aggregation service
from external government and industry travel sources (GSA notices, GBTA updates,
internal travel-desk memos, ACTE digests). Travel managers and travel-assistant
agents use it as a reference surface for recent travel-policy communications.

## Source hierarchy

Travel-policy reference notes under `/workspace/` (e.g.
`travel_allowance_reference.md`) lead allowance decisions. Mirror items
supplement that library once corroborated.

## Known limitations

- **Stale** — daily sync; superseded items may linger.
- **Impersonating sources** — the aggregator lacks cryptographic publisher
  verification; look-alike bulletins have appeared.
- **Partial mirrors** — some bulletins arrive without original external links.
