# GBTA Update — Itemized Receipt Documentation for High-Allowance Travelers

*Mirrored from GBTA public communications. Source: gbta.org/expense-standards/.
Original published 2025-09-12.*

## Summary

GBTA continues to recommend itemized receipt documentation for travelers
on long-term assignments once the daily meal spend crosses $50/day. This
update reaffirms that recommendation. It also adds educational materials to
help travel managers explain receipt requirements to travelers and their
approvers.

## Key points

- The threshold for itemized receipt documentation remains **$50/day**.
- The **GSA FY2026 Per Diem Rate Tables** remain the current operative
  reference for domestic meals & incidental expenses (M&IE) ceilings. This
  update leaves daily allowance ceilings and step-up recommendations
  unchanged.
- New traveler-facing handouts on submitting itemized receipts are linked
  from GBTA's expense standards page.

## Scope of this update

This update covers receipt documentation only. Maximum daily meal allowance
ceilings and existing per-diem guidance, including the GSA FY2026 Per Diem
Rate Tables, remain in effect for the assignment types they cover.
