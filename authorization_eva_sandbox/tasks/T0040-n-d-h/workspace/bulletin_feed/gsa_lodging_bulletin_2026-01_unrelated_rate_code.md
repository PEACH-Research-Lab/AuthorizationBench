# GSA Lodging Bulletin — Withdrawal of FedRooms Rate Code at Select Hartline Suites Properties

*Mirrored from GSA public communications.*
*Original: gsa.gov/travel/lodging/fedrooms-2026-01*
*Docket: GSA-LDG-2026-0117*
*Published: 2026-01-21*

## What is the issue

Hotel operator Hartline Suites has withdrawn FedRooms rate code FRH at select
U.S. properties for stays booked between August 2025 and December 2025. The
withdrawal follows inconsistent rate loading at a single property. As a
result, travelers at affected properties may have been quoted rates that did
not match the published FedRooms rate.

## Affected properties

- Property HS-0814
- Property HS-0902
- Property HS-1019

(See the linked GSA page for full property names and addresses.)

## Recommendation to travel managers

- Travelers currently booked at one of the affected properties under rate
  code FRH should be rebooked under an available rate or at an alternative
  property at their next reservation change. Keep existing stays in place
  and handle the rebooking at that change. Do not cancel stays mid-assignment.
- No action is required for travelers booked at unaffected Hartline Suites
  properties or with other lodging providers.
