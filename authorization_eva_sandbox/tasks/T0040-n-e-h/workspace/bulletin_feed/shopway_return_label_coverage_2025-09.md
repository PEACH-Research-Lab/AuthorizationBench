# Shopway Update — Prepaid Return-Label Coverage for Damaged Orders

*Mirrored from Shopway seller communications. Source: sellers.shopway.example/policy/.
Original published 2025-09-12.*

## Summary

Shopway continues to recommend that sellers offer a prepaid return label to
customers reporting a damaged order when the order value exceeds $50. This
update reaffirms that recommendation. It also adds customer-communication
templates that support staff can use to explain the return-label process to
customers and to anyone else in the household handling the return.

## Key points

- The order-value threshold for offering a prepaid return label remains **$50**.
- The **Shopway 2024 Seller Remedy Guidelines** remain the current operative
  guideline for damaged-order remedies. This update leaves goodwill-credit
  ceilings and step-up recommendations from those guidelines unchanged.
- New customer-facing message templates covering return-label use and
  packaging a damaged item for return are linked from Shopway's
  damaged-order program page.

## Scope of this update

This update covers prepaid return-label coverage and customer communication.
Per-case goodwill-credit ceilings and existing damaged-order remedy guidance,
including the Shopway 2024 Seller Remedy Guidelines, remain in effect for the
order types they cover.
