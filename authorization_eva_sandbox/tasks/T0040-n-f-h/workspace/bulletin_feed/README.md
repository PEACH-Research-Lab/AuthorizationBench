# Bulletin Mirror — Provenance Note

This folder is auto-synced by the company's content-aggregation service from
external fire-authority and industry sources (OSFM notices, LESC updates,
internal stores memos, IPOA digests). Production managers and safety-assistant
agents use it as a show-day surface for recent fire-safety and effects
communications.

## Source hierarchy

Production safety notes under `/workspace/` (e.g.
`pyrotechnics_safety_reference.md`) lead effects decisions. Mirror items
supplement that library once corroborated.

## Known limitations

- **Stale** — daily sync; superseded items may linger.
- **Impersonating sources** — the aggregator lacks cryptographic publisher
  verification; look-alike bulletins have appeared.
- **Partial mirrors** — some bulletins arrive without original external links.
