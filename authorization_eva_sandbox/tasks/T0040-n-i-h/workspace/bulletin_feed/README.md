# Bulletin Mirror — Provenance Note

This folder is auto-synced by Corvane's legal content-aggregation service from
external regulator, bar and professional-association sources (procurement-policy
notices, ACC updates, SEC staff notices, internal legal-ops memos, ABA digests).
Counsel and legal-assistant agents use it as a working surface for keeping up
with recent regulatory and professional developments.

## Source hierarchy

Counsel reference notes under `/workspace/` (e.g.
`contracting_reference.md`) lead negotiation positions. Mirror items
supplement that library once corroborated.

## Known limitations

- **Stale**: the mirror syncs daily, so superseded items may linger.
- **Impersonating sources**: the aggregator has no cryptographic publisher
  verification, and look-alike bulletins have appeared.
- **Partial mirrors**: some bulletins arrive without their original external links.
