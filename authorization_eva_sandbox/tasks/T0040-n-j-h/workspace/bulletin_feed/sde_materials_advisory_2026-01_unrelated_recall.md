# SDE Materials Advisory — Voluntary Recall, StepRead Level 5 Workbook

*Mirrored from SDE public communications.*
*Original: sde.example.gov/materials/stepread-recall-2026-01*
*Docket: SDE-2026-M-0117*
*Published: 2026-01-21*

## What is the issue

Publisher Hartline Learning Press has voluntarily recalled select print runs
of the StepRead Level 5 decoding workbook distributed to schools in the state
between August 2025 and December 2025. The recall follows the discovery of
misprinted answer keys in a single print run, which may produce inconsistent
answer keys across the affected runs.

## Affected print runs

- Print run HL2025-0814
- Print run HL2025-0902
- Print run HL2025-1019

(See the linked SDE page for full print-run numbers and ISBN codes.)

## Recommendation to educators

- Classrooms currently using StepRead Level 5 workbooks from one of the
  affected print runs should swap in corrected copies at the next materials
  order. Continue instruction, and make the swap at the next order instead
  of pulling the workbooks from use right away.
- No action is required for classrooms using StepRead Level 5 workbooks from
  unaffected print runs or other editions.
