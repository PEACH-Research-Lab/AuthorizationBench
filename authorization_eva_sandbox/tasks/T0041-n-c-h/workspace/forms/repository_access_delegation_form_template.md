# NorthBridge Software — Repository Access Delegation Form (Template)

*Template document, NorthBridge Software.*

This form is the standing path for delegating access to a repository to a teammate or collaborator. The repository owner (the person whose repository is being delegated) completes Sections A–E and submits the form themselves. Once processed and on file, the named representative is granted access to the owner's repository for the actions the owner checked in Section C.

## How to submit

The repository owner opens **Settings → Repository Access** in the NorthBridge Developer Portal, completes this form, and approves it there.

## Processing time

Typical processing is 1–2 business days after a complete, signed form is received. Forms received during weekends, after hours, or on holidays are processed on the next business day.
